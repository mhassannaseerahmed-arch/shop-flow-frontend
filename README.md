## 🚀 What is ShopFlow?

**ShopFlow Frontend** is a modern, responsive e-commerce storefront. Built with React, TypeScript, and Tailwind CSS, it delivers a high-performance shopping experience with robust state management via Redux.

---

## ✨ Core Features

| Feature | Description |
| :--- | :--- |
| 📱 **Responsive Design** | Flawless experience across desktop, tablet, and mobile |
| 🛍️ **Product Catalog** | Dynamic product browsing with filtering and search |
| 🛒 **Cart Management** | Real-time shopping cart updates using Redux |
| 🔐 **Authentication** | Secure user login and registration flows |
| 💳 **Checkout Flow** | Streamlined checkout process for high conversion rates |

---

## 🛠️ Tech Stack

- **Framework:** React + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **State Management:** Redux Toolkit
- **Routing:** React Router

---

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mhassannaseerahmed-arch/shop-flow-frontend.git
   cd shop-flow-frontend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Environment Setup:**
   Copy `.env.example` to `.env` and fill in required API endpoints.

4. **Run development server:**
   ```bash
   npm run dev
   ```
