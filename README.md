# ShopFlow Frontend

Developed by **Hassan Naseer Ahmed**

Modern e-commerce frontend built with **React**, **Tailwind CSS**, and **Redux**.

### Features
- Responsive Design
- - Product Catalog
  - - Cart Management
    - - User Authentication (Integration with Backend)
      - - Checkout Flow
       
        - ### Tech Stack
        - - **Framework:** React
          - - **Styling:** Tailwind CSS
            - - **State Management:** Redux / Redux Toolkit
              - - **Routing:** React Router
               
                - ### Getting Started
                - 1. Clone the repository.
                  2. 2. Install dependencies:
                     3.    ```bash
                              npm install
                              ```
                           3. Set up environment variables (see `.env.example`).
                           4. 4. Run the development server:
                              5.    ```bash
                                       npm run dev
                                       ```
